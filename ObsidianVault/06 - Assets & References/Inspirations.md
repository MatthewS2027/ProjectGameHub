# 🔗 Inspirations

> Reference games, media, and links that inform the design of this project.

---

## 🎮 Reference Games

### Destiny / Destiny 2
- **Developer:** Bungie
- **Why it's referenced:** The gold standard for loot-based FPS. The "gunfeel," reward loop, and exotic weapon design are directly referenced.
- **Key takeaways:** Every gun should feel unique. Loot should create excitement. The moment-to-moment combat must be fun on its own.
- **Link:** https://www.destinythegame.com

---

### Enter the Gungeon
- **Developer:** Dodge Roll
- **Why it's referenced:** The definitive top-down roguelite. Room-based structure, massive weapon variety, tight dodge mechanics.
- **Key takeaways:** Dodge roll should have i-frames. Rooms should be self-contained encounters. Synergies between items add replayability.
- **Link:** https://store.steampowered.com/app/311690/Enter_the_Gungeon/

---

### Hades
- **Developer:** Supergiant Games
- **Why it's referenced:** Masterclass in roguelite run structure. Narrative integration, boon system, and run pacing.
- **Key takeaways:** Every run should offer meaningful choices. Failing a run still feels rewarding. Characters and story should be woven into the gameplay loop.
- **Link:** https://store.steampowered.com/app/1145360/Hades/

---

### Diablo (series)
- **Developer:** Blizzard Entertainment
- **Why it's referenced:** Foundational loot game. Rarity tiers, item affixes, build diversity, and enemy density.
- **Key takeaways:** Loot tiering creates excitement. Enemy density creates tension. Builds should allow multiple valid playstyles.
- **Link:** https://diablo4.blizzard.com

---

### Dead Cells
- **Developer:** Motion Twin
- **Why it's referenced:** Fluid animation, fast combat, tight level design, and satisfying hit feedback.
- **Key takeaways:** Animation must feel crisp. Hit stop and screenshake are essential for impact. Levels should reward exploration.
- **Link:** https://store.steampowered.com/app/588650/Dead_Cells/
