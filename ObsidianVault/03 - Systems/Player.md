## 🕹 Controls

| Action | Keyboard / Mouse | Controller |
|---|---|---|
| Move | WASD | Left Stick |
| Aim | Mouse | Right Stick |
| Shoot | Left Click | Right Trigger |
| Dodge / Roll | Space | A / Cross |
| Ability 1 | Q | LB / L1 |
| Ability 2 | E | RB / R1 |
| Reload | R | X / Square |
| Interact | F | Y / Triangle |
| Pause | Escape | Start |

## 🩺 Health & Healing

- Health does **not** regenerate passively
- Healing sources: health packs (dropped or carried), shop items
- Some upgrades may add a small regen effect
